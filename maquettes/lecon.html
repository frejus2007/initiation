Trouver un fichier caché sous Linux

← Retour au parcours

Objectif pédagogique

Comprendre la convention des fichiers masqués sous UNIX (préfixe .), utiliser l'option -a de la commande ls et extraire la chaîne secrète d'un fichier protégé.

Instructions pratiques

Dans votre terminal local, placez-vous dans votre répertoire d'entraînement :

terminal — local 
# 1. Lister tous les fichiers, y compris les fichiers masqués
$ ls -la
drwxr-xr-x 2 user user 4096 oct 16 14:00 .
drwxr-xr-x 4 user user 4096 oct 16 14:00 ..
-rw-r--r-- 1 user user  128 oct 16 14:00 notes.txt
-rw------- 1 user user   42 oct 16 14:00 .archive

# 2. Afficher le contenu du fichier masqué repéré
$ cat .archive
CTFABJ{…}

Sous Linux, les fichiers dont le nom commence par un point ne sont pas chiffrés : ils sont simplement omis par défaut par les outils d'affichage standard.

Validation de l'exercice

Flag validé avec succès (+80 points). Vous pouvez passer au module suivant.
Ce flag ne correspond pas à l’exercice. Relisez le fichier masqué avec cat .archive.

Ce qu'il faut retenir

  • L'option -a de ls affiche toutes les entrées (all), y compris celles débutant par ..
  • Pour rechercher rapidement tous les fichiers cachés d'une arborescence : find . -name ".*".
  • Le nettoyage de l'exercice local s'effectue simplement avec rm -rf ~/ctfacademy/lecon-02.
